# AI Chatbot With Memory

A conversational AI chatbot that remembers previous messages using conversation history.

## Features
- AI conversation
- Memory handling
- Continuous chat loop
- Personalized responses

## Technologies Used
- Python
- Google Gemini API
- Google Colab

## Concepts Learned
- Lists
- Loops
- Functions
- AI memory systems
- Stateful conversations

## Example
User: My name is Rahul

AI: Nice to meet you Rahul!

User: What is my name?

AI: Your name is Rahul.
